here,I simply bring up some Field_and_wave simu s,done via conventional numerical methods such as finite element method,variential methods etc...

description of each::


1-telegtapher:A Python-based numerical simulation of time-harmonic electromagnetic wave propagation along a transmission line in case they are too close(explicitly speaking telegrapher) in which lines couples with each other leading to the beautiful telegrapher equations with a varying cross-sectional geometry(to do so we incline the upper line).
This project calculates the spatial voltage distribution across a coupled transmission line system and visualizes the wave propagation over time using animated contour plots.
